# Decisions log

Each decision: question, option chosen, why (order: existing code/docs/UI promise → industry practice (Impact,
PartnerStack, Refersion, Rewardful, Shopify; for storage: AWS/S3 guidance) → safest for money/data → easiest to change
later), and the commit. Repos: BE = partner-iq-backend, FE = partner-iq-frontend, AP = partner-iq-affiliate-portal.

## Assets & Bundles audit (branch audit/assets-bundles)

| # | Question | Decision | Why | Commit |
|---|---|---|---|---|
| A0 | Branch name: the first version of the task said `feature/assets-bundles`, the hard limits allow only `audit/*` | `audit/assets-bundles` in every repo (the revised task names it too) | Hard limit "work only on audit/* branches". | — |
| A1 | Where the e2e tests live | `e2e-assets/` (separate from the coupons audit's `e2e/`) | avoids add/add conflicts when both audit branches are merged; the coupons branch is not merged yet. | — |
| A2 | MinIO install | Built from source through the Go module proxy (official binary and GitHub downloads are blocked by the network policy) | Real S3-compatible service for every scenario, as required. | — |
| A3 | `xlsx` during `npm install` | Temporarily pointed at registry 0.18.5 for the install, original spec and lock entry restored | `cdn.sheetjs.com` is blocked; the committed manifest must keep the team's chosen xlsx build. | — |
| A4 | Storage design | One `@Global` `StorageModule` (`src/common/storage`) exposing the abstract `StorageService`; one S3 provider (AWS SDK v3 `client-s3` + `lib-storage`), client created once; typed config validated at startup (`STORAGE_*`); one key builder `orgs/{org}/assets/{asset}/v{n}/{random}` (user file name only in `Content-Disposition`) | Required by the task; AWS guidance (random keys, private bucket, presigned GET). Changing provider = one new class implementing `StorageService`. | BE 6482759, 51b41fe |
| A5 | MinIO has no PublicAccessBlock API and rejects an `AbortIncompleteMultipartUpload`-only lifecycle rule | Code still sends both (works on AWS); on MinIO: anonymous access is proven denied by a probe, stale multipart uploads expire by `MINIO_API_STALE_UPLOADS_EXPIRY=24h` and the app's own `abortStaleMultipartUploads` job | Keep the AWS setup as code; prove the effect on the test service instead of the API call. | BE 51b41fe |
| A6 | Per-file limit | Keep the existing 200 MB (`STORAGE_MAX_FILE_BYTES`), images for logos/avatars 5 MB | Task: "keep the existing per-file limit". | BE 51b41fe |
| A7 | dbStore vs TypeORM for assets | Asset module uses TypeORM repositories only; dbStore is still read for programs/tiers/affiliates (owned by other modules) | Task forbids dbStore for the usage counter; the background upsert of dbStore cannot be part of a transaction with the counter. `store.ts` not edited. | BE 51b41fe |
| A8 | Tier comparison | Compare levels only inside the required tier's program; tier rewards (`rewardsConfig.assetBundleIds`) on tiers at or below the affiliate's level also unlock a bundle | Levels of different programs are unrelated; existing tier config already stores bundle ids. | BE 51b41fe |
| A9 | Public file inside a restricted bundle | Most restrictive wins: the file stays locked unless the affiliate can open at least one bundle containing it | Safest for data; a "public" flag must not leak tier-only material. | BE 51b41fe |
| A10 | `AFFILIATE_SEGMENT` bundles | Hidden from affiliates, not offered in the admin form | No segment model exists; showing them to everyone was a leak. | BE 51b41fe, FE a981fdf |
| A11 | "Removed" affiliate | Affiliate status not ACTIVE, deleted, or no ACTIVE program membership → no lists, no new download links | Existing links expire in ≤ 5 minutes. | BE 51b41fe |
| A12 | Download counting | One count per affiliate × file × minute (idempotency key) | Double clicks and retries must not inflate counts; matches common analytics practice. | BE 51b41fe |
| A13 | Logos / avatars | Moved from Cloudinary to `StorageService`; not counted toward the 3 GB (`countsTowardQuota=0`); served through `GET /api/v1/media/:id` (302 to a signed URL); old logos are not deleted automatically (growth risk, reported) | They are branding, not library files; the task scopes the limit to asset originals and versions. | BE 51b41fe, FE a981fdf, AP d12b936 |
| A14 | VIEWER / ANALYST and the Assets page | They have no `assets.*` permission on the backend, so the page is removed from their navigation | Backend permission catalog is the source of truth; a page of 403s is a broken promise. | FE a981fdf |
| A15 | Concurrent uploads per organization | 5 (`STORAGE_MAX_CONCURRENT_UPLOADS_PER_ORG`), counted in the same conditional UPDATE as the reservation; 429 when exceeded | Task suggests 5; one atomic counter, no race. | BE 51b41fe |
| A16 | EXIF / GPS | Originals are stored byte-exact (GPS kept); thumbnails are re-encoded by sharp with metadata stripped | Changing originals breaks checksums and brand files; previews are what get shown widely. Reported for review. | BE 51b41fe |
| A17 | Malware scanning | Not added: magic-byte type check, executable/markup rejection, attachment disposition and nosniff only | No scanner available in the environment; reported as not tested / recommended. | — |
| A18 | Declared size vs Content-Length | Reserve `min(X-File-Size, Content-Length)`; abort when more bytes than reserved arrive | A too-small declared size can never use more than reserved; a too-large one cannot block more than the body. | BE 8e9529b |
| A19 | Text / HTML / link assets | Keep content versions in the database (no file, 0 bytes counted) | Existing behaviour; they use no object storage. | BE 51b41fe |
| A20 | Bundle archive and bulk "archive" | `POST …/archive` needs `assetBundles.delete`; bulk ARCHIVE (move to trash) needs `assets.delete` | Before, a role without delete could remove things through the side door. | BE 51b41fe |
| A21 | Thumbnails | Only for raster images ≤ 25 MB, 40 M pixel input cap, 15 s timeout, serial queue | Decompression-bomb safety; larger images show an icon. | BE 51b41fe |
| A22 | Thumbnails in lists | Lists embed 5-minute signed thumbnail URLs | `<img>` cannot send a bearer token; signed URLs keep the bucket private. | BE 51b41fe |
| A23 | Folders | Derived from assets' `folderPath` (no folder table); "New folder" in the UI only pre-fills the upload/move target | Existing data model; adding a table is a larger change for later. | FE a981fdf |
| A24 | Old org-scoped affiliate asset routes | Removed; the portal uses `/api/v1/affiliate/me/assets*` and `/asset-bundles*` | One access-checked path. | BE 51b41fe, AP d12b936 |
| A25 | Legacy asset rows whose "file" is only a client-supplied URL / key | Not downloadable (`legacyFileMissing`) until migrated by `npm run storage:migrate-legacy`; migration copies only from allowlisted hosts, verifies size + SHA-256, keeps the originals | Never fetch arbitrary URLs from the server (SSRF); never delete original data. | BE da9337f |
| A26 | Tax certificates (client-supplied URL) | Not moved to storage in this audit; listed in the inventory | Belongs to payouts/tax, not assets; billing/tax files are out of scope. | — |
| A27 | What the reconciliation job sets the counter to | The sum of the counted records (stored_objects); the bucket listing is reported (inStorageBytes, orphans, records without objects, size mismatches) for a person to resolve | Every delete subtracts a record's size; a counter taken from the listing drifts once a broken record is deleted. Never delete data on a guess. | BE 49f7027 |
| A28 | May a new version change the file type? | No: same type family as the current file (415 VERSION_FILE_TYPE_MISMATCH); a different type is a new asset | The UI promises it; bundles and affiliate pages must not silently switch a banner to a PDF. | BE 5925aae |
| A29 | Portal asset list size | Paged, newest first, default and maximum 500 per request (`page`, `limit`, `meta.total`); the portal loads the first page | A 20k-file organization froze the API (scenario AM). A paging UI in the portal is a follow-up (assets-audit.md §9). | BE d03416e |
| A30 | Admin bundle list contents | Summaries only (counts, sizes, tier); files via GET /asset-bundles/:id (the admin UI already loads the detail on click) | 1,000 bundles: 4.7 s / 7.7 MB → 54 ms / 734 KB. | BE d03416e |
